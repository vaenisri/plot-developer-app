# Character-Driven Story Tool

A story development tool designed to help writers develop their stories
without writing the story for them.

## What it does

The current V1 allows writers to:

- Build characters using wound, flaw, misbelief, and strength
- Choose between different plot structures
- Organize beats by story stage
- Identify flaw-driven, strength-driven, and external beats
- Visualize the cost/stakes of beats through a line chart

## Why I built it

As a writer, I often found that knowing what happens next isn't
the hardest part of writing a story. Understanding why a character
makes a particular choice can be much harder.

I built this project to explore whether a software tool could help
writers examine their characters and story structure without
generating the writing for them.

## Built with

- Python
- Streamlit

## Current status

V1 prototype.

The next stages will focus on testing the tool with writers,
improving the character-to-plot relationship, and refining the
story analysis features.

## Running locally

1. Clone the repository
2. Install the requirements
3. Run:

python -m streamlit run story.py
