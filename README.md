# Character-Driven Story Tool

A story development tool designed to help writers develop their stories
without writing the story for them.

## What's New in Version 2

Based on direct testing and feedback from 5 active writers, Version 2 introduces deeper integration between character psychology and scene drafting:

* **Guided Story Stages:** Interactive stage descriptions that explain what each beat represents in character-driven narrative frameworks.
* **Refined Beat Checker:** Live tracking and warnings when external plot mechanics threaten to overpower character agency.
* **Drafting Studio:** A dedicated, side-by-side writing space that pins character wounds, misbeliefs, and beat choices directly next to the scene editor.
* **Editorial UI/UX:** A tactile, distraction-free vintage notebook aesthetic designed to keep writers focused on craft.

## What it does

The current version allows writers to:
* Build characters using wound, flaw, misbelief, and strength
* Choose between different plot structures (Hero's Journey and Three-Act Structure)
* Organize beats by story stage with contextual guidance
* Identify flaw-driven, strength-driven, and external beats
* Visualize the cost/stakes of beats through a live line chart
* Draft scenes directly alongside character psychology profiles
